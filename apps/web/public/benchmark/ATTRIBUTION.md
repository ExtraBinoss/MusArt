# Local performance photographs

These JPEG files were downloaded from Unsplash on 27 October 2026 for the MusArt composition/performance fixture. They are not generated images. The [Unsplash License](https://unsplash.com/license) applies separately from the source code.

There are **50 image assets**, made from **10 source photographs with five focal crops / JPEG quality variants each**, at 1280 × 960 pixels. The manifest records the original image URLs, author/page when verified, file sizes and SHA-256 checksums. Repeated photographs are intentional; the benchmark still uses 50 independent image layers with effects.

Verified credits include Sebastian Unrau (forest), Luca Bravo (boathouse), and Sean O. (beach). Other images retain the precise Unsplash CDN source URL in the manifest; authorship is not guessed. This fixture is a creative editor contact sheet and is not a stock-image service.

After installation, all benchmark images are served from `/benchmark/` on the same local server. The load test does not contact Unsplash or another image CDN.
