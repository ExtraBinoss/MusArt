# Melt brand artwork

The current identity is the genuine eight-petal Dahlia and wonder expression from
Maskot's MIT engine, sampled at 0.75 seconds. Canonical SVG sources, rendering
recipe and SHA-256 values live in `apps/web/src/ui/brand/assets/`.
Run `bun scripts/brand-assets.ts` to regenerate the identical public SVG copies.
The inline interface logo is painted by the same engine and frame.

The earlier MusArt PNGs and favicon were supplied by the project owner on
2026-10-27 as `MusArt-Icones-PNG`. They remain unmodified here for provenance and
compatibility; the current interface does not load them.
