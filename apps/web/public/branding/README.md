# MusArt brand artwork

Supplied by the project owner on 2026-10-27 as `MusArt-Icones-PNG`. The PNGs and multi-size favicon are preserved verbatim, including their transparency. All sizes derive from the same 1254 × 1254 master.

The interface uses the 32/64 pixel files for standard/high-density displays. The browser uses the provided favicon, Apple Touch icon and 192/512 pixel install icons. Larger originals remain available for future uses; they are not loaded by the editor interface. No light/dark recoloring or CSS filter is applied.
