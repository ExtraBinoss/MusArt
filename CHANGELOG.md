# Changelog

All notable changes are recorded here in English. MusArt uses a synchronized [Semantic Versioning](https://semver.org/) release number across its workspaces.

## [Unreleased]

### Added

- **Visible project templates:** the dashboard exposes the editable AFTERHOURS techno poster alongside canonical social, print and screen canvas formats with original brand icons. Selecting a template creates an independent, validated and saved project; the poster preview is exported from its real GPU composition.
- **Magic Search:** a keyboard-accessible Ctrl/Cmd+K spotlight with categorized tools, imports, project and viewport actions, effects, pages, cross-page layers and a shortcut reference. Search normalizes accents, reports available/disabled actions and routes operations through the existing engine and services.
- **Scroll surfaces:** reusable boundary shadows update imperatively across the dock, inspector, layer tree, palettes, effect popovers and command lists. Thin scrollbars share one theme; short viewports retain normal vertical scrolling and 35-pixel dock controls. The customization catalog virtualizes its visible command rows, while native dock dragging previews spring transitions and persists only a valid completed reorder.
- **Customizable dock:** a compact **…** spotlight trigger and persistent pinned shortcuts drawn from the shared action/effect registry. Drag reordering has a local visual preview; the customization popover provides searchable pinning, unpinning and keyboard-accessible move buttons. Stored command IDs are allowlisted, deduplicated and bounded independently of document history.
- **Font library:** a searchable, categorized and virtualized Google Fonts picker, selected-text hover/keyboard previews, cancellable drafts and single-edit application. TTF/OTF imports and selected downloads persist across projects in a browser-wide IndexedDB library. Supported browsers discover local font metadata on picker opening through native permission controls; originals are read only when chosen. Projects retain family references rather than embedding font binaries.
- **Techno poster template:** a real, lazily loaded **AFTERHOURS — Techno** artboard action in Magic Search and dock customization, with editable typography, gradients, groups, wireframes and GPU effects. Adding it is undoable and a project switch cancels a stale template request.
- **Analytical GPU text:** a strict TypeScript and TSL port of the ts-slug curve/band approach, instanced glyphs, local outline fonts, HarfBuzz shaping, kerning, ligatures, variable weights and native-scale export. Text fills support linear/radial RGBA gradients with two to eight stops and hard transitions, while keeping masks, effects and blend modes in the existing GPU graph.
- **Text quality controls:** zoom/device-density preview resolution with bounded retained-target allocation, explicit font provenance and tests that detect Canvas2D text raster calls as well as GPU readbacks.
- **Creative editor:** a central multi-artboard canvas, floating left dock, compact project menu and name pill, export beside Design/Animate, and a pinned inspector split from the layers panel with resizable dividers.
- **Shared artboards:** project pages appear together in a deterministic workspace, with screen-sized headings, direct activation, rename/delete menus and destination-aware image drops. One retained editing scene serves the active artboard; inactive artboards lease real persisted GPU thumbnails only while visible. Switching artboards preserves the world view and page-local tool/guide coordinates.
- **Canvas quick add:** a contextual plus in the active artboard heading reveals on artwork/header hover or keyboard focus and adds an artboard through the shared command registry. Double-clicking empty workspace opens a compact categorized, searchable Radix popover backed by Magic Search's addable commands. Text and primitives become centered editable layers in the active artboard; imports keep native file-picker activation and shapes open the existing shapes/icons/brands library. Artboard content is excluded from the double-click gesture, and stale or playback sessions cancel safely. Both add/options controls include translated Radix tooltips.
- **Shared GPU previews:** bounded, deduplicated layer/effect and export previews borrow the existing thumbnail renderer, reject stale/aborted results and retain at most 64 blobs within 8 MiB. Explicit export previews take priority after pointer release without waiting for the background quiet timer.
- **Compact color picker:** a saturation/value pad with genuine vertical hue and alpha sliders, direct hexadecimal editing and a native screen-color picker where supported. Sampling preserves the chosen alpha, cancels abandoned requests and rejects stale results; previews remain imperative, with one committed undo entry per completed gesture and restoration on cancellation.
- **Themes and accessibility:** English and French interface resources, light/dark/system themes, saturated blue primary controls, shadcn/Radix Select, Tabs, menus, dialogs and Kbd hints, and tooltips without decorative arrows.
- **ResumI controls:** reusable scrub-label numeric inputs with direct typing, units, snapping, keyboard editing, cancellation and one committed edit per gesture.
- **Document engine:** validated portable projects, multiple pages, nested layers and groups, selection, atomic command transactions, undo/redo, alignment, distribution and world/local geometry utilities. Commands are dispatched through a typed registry to domain-specific handlers.
- **Layer attachments:** a virtualized tree presents ordered effect children and linked mask references beneath their owner, with real parameter popovers, per-effect blend/opacity, palette presets, visibility, removal and effect-stack drag reordering. Visible rows request abortable final GPU thumbnails and explicitly revoke their blob URLs.
- **Layer editing:** rename, duplicate, reorder, group, ungroup, visibility, locking, opacity, transforms, image aspect locking, text content and typography, fills, strokes and layer-specific effects. Dragging projects the layer tree live with reduced-motion-aware spring transitions; nested-group and Alt-mask targets are validated without changing the document until drop, and cancellation restores the original order.
- **Shapes and artwork:** a unified last-used shape tool with long-press, right-click and keyboard access to searchable, virtualized shape/icon/brand catalogs copied from ResumI. Original multicolor paints and attribution are retained; supported SVG artwork can be imported as editable vector data.
- **Guides and layout:** editable page/layer guides, draggable rulers, margins, padding, snapping, alignment and distance arrows, including nested group transforms. Social and print presets include appropriate dimensions, editable safe areas and real platform marks.
- **GPU composition:** Three.js WebGPURenderer, React Three Fiber and TSL, with the same node graphs on the WebGL fallback. Retained render targets, ping-pong effects, normal-layer batching, isolated groups, bounded resource caches and demand rendering keep intermediate pixels on the GPU.
- **Blending:** 26 layer/group blend modes, including darker/lighter color, darkening, lightening, contrast, difference and hue/saturation/color/luminosity families, with alpha-aware compositing.
- **Effects and corrections:** modular GPU effects and adjustments: dither, ASCII, procedural gradients, brightness, contrast, grayscale, blur, exposure, saturation, hue, vibrance, temperature, tint, gamma, invert, sepia, threshold, posterize, grain, halftone and vignette.
- **Color workspaces:** sRGB, Display-P3 working-space conversion to the current sRGB output, and a generic CMYK soft proof. Raster exports remain RGB; the proof does not claim ICC press-profile support.
- **Masks and selections:** non-destructive asset and layer/group masks, alpha/luminance coverage, inversion, enable/disable controls, mask drag/drop affordances, dependency-cycle validation, a connected-color magic wand and local SlimSAM object segmentation.
- **Import and export:** bounded bulk image imports, drag/drop and clipboard handling, portable `.musart` documents with originals, PNG/WebP/JPEG through native browser encoders, multi-page ZIP exports, and reusable GPU render sessions.
- **Local projects:** IndexedDB manifests and original assets stored separately, transactional writes, coalesced autosave and restoration of the last project.
- **Project library:** paginated cards, creation, opening, inactive-project renaming, duplication and deletion. Thumbnail-first cards keep page names and project management actions in readable overlays; a hover-only carousel slides horizontally every 1,400 ms, pausing for keyboard focus, hidden/offscreen cards and reduced-motion preferences. Manual swipe, arrow and dot navigation is not exposed.
- **Shared dashboard:** the MusArt logo opens Projects and Templates with a neutral animated tab indicator, a portable-project import action and a clear custom-canvas creation flow. The same interface welcomes first-time users without persisting a placeholder project. The settings gear opens preferences and the customizable shortcut editor; preferences also remain accessible through Magic Search.
- **Thumbnail pipeline:** native WebP encoding, revision checks, lazy blob URL leases, a bounded retained GPU session and idle scheduling that pauses during interaction. Deleted projects and stale page revisions cannot be republished by delayed jobs.
- **Storage insights:** per-project logical payload breakdowns, cached incremental counters for originals, thumbnails and history, and a separately labelled browser origin storage estimate. Projects expose a confirmed clear-history action.
- **Durable creative history:** an automatically recorded journal separate from the project manifest. It stores completed transactions as compact deltas and action summaries, with sparse checkpoints, original-asset pooling, bounded pagination and adjustable retention from 10 to 100,000 entries; the default is 10,000.
- **Timelapses:** deterministic replay and scrubbing in Animate, a separate JSON history export, and MP4/WebM encoding through Mediabunny from a retained GPU canvas with explicit timestamps and encoder backpressure.
- **Headless tools:** document creation, atomic command application, still rendering and editor screenshots, plus an opt-in automation API for document, history and thumbnail operations.
- **Branding:** the supplied transparent MusArt logo, favicon, Apple Touch icon and installation icons, preserving the original artwork and resolutions.
- **Open-source preparation:** MIT project license, English README and contribution documentation, preserved third-party licenses, local asset provenance, and official Meta/Cerebral Valley hackathon references.
- **Version management:** synchronized workspace versions, a deterministic version checker and a release script that moves reviewed `Unreleased` notes into dated releases.

### Changed

- Opacity and blending now belong above Layers, with disabled empty-selection controls, explicit mixed values and one atomic committed edit for multiple layers. Footer icons add effects and corrections; grouping and ungrouping use one context-menu action, and layer ordering uses drag and drop.
- Alignment chooses the common group, selection bounds or artboard automatically. Numeric fields display at most two decimals while preserving untouched document precision; Design/Animate tabs and layer rows use neutral active states.

- Bulk per-layer patches use one indexed command and one undo entry, including distinct transforms across 10,000 selected elements. Selection validation and immutable geometry lookup use reusable indexes instead of repeated document scans.
- Render jobs share an indexed, memoized source-key resolver, and mask validation indexes group children once. Large sibling/group collections no longer trigger a full document scan for each source or group.
- Image export sits beside Design/Animate and opens below its trigger in a popover. It previews the actual GPU result, defaults to cropped selected content, and offers whole-artboard or multi-artboard ZIP output. Transparent preview padding, fit/zoom and scrolling help inspect the result; foreground requests avoid the background quiet delay. Selected exports retain group transforms and ancestor processing, with independent copies of referenced mask subgraphs so overlapping selections stay correct.
- Hover, tabs and layer selection use neutral tones in both themes; the selected tool and export action retain the blue action accent. Canvas-format cards use deterministic decorative gradient palettes while preserving their canonical blank-document behavior.
- Live colors, opacity, geometry and effect parameters use imperative previews and stable GPU uniforms. The document remains unchanged until the gesture commits; multiple selected layers share a single preview patch.
- Project controls share a consistent height, header page tabs give way to the shared artboard workspace, and add-artboard actions remain available through the dock and spotlight.
- The project-name control is one button opening a popover below it. Renaming, saving and downloading `.musart` files stay together with divided actions; the dashboard focuses on project management and templates.
- Trackpad scrolling pans both axes within workspace bounds. Ctrl/Cmd+wheel uses normalized, spike-limited deltas and a short, interruptible animation around the pointer; continuous frames do not rerender the editor. Plus/minus share the motion controller, 100% resets exactly, fit remains in Magic Search, and reduced-motion preferences apply immediately.
- Original images are uploaded and reused across composition updates; vector paths are triangulated once per geometry identity. Guide, margin and padding metadata no longer invalidates painted layer sources.
- Project opening and saving avoid historical event scans. History pages are capped at 100 entries, and indexed checkpoints bound retention work.
- New project and original-mask IDs use durable UUIDs at web persistence boundaries. The pure engine retains its deterministic session-local allocator.
- Documentation records rendering contracts, TSL/WebGPU decisions, segmentation behavior, storage accounting and reproducible load-test protocols.

### Fixed

- Enforced mask dependency depth independently of layer ordering and protected cached geometry from shallow-frozen documents and external mutations of matrices, bounds, child lists or lookup maps.
- Deferred layer menu operations retain the invoking selection and reject changed document/selection scopes instead of retargeting a later selection.
- Blend selectors preview hovered and keyboard-focused modes without changing the document, restore on cancellation and commit one selected choice. Shared Select chevrons animate their Radix open state and honor reduced-motion preferences.

- Kept wheel/hand panning on imperative compositor transforms, with one settled React update per gesture and no guide/selection geometry churn. Reused indexed immutable geometry during selection and bulk movement, applied distinct layer patches in linear time, and represented large selections with one exact collective frame while preserving every selected layer.

- Selected exports copy complete mask dependency graphs under deterministic private IDs, so painting only part of a shared mask source cannot change the target mask. Original painted IDs, processing ancestors, rotations and referenced asset bytes remain intact; copied effect/guide IDs avoid the caller’s reserved project scope.

- Retired deleted project IDs atomically, preventing late saves and journal writes from resurrecting removed payloads across sessions. Explicitly reimporting a deleted portable project recovers it under a fresh UUID.
- Kept background project duplication from changing the last-opened project and remembered the actual replacement when deleting the active project.
- Matched recenter to the actual 32-pixel plus/minus button height, vertical alignment, blur and floating background; removed the permanent fullscreen-style fit button and retained recenter only after moving away from the workspace center.
- Kept historical playback safe when a past frame references a deleted page by presenting its geometry in the current active artboard slot without changing the canonical document.
- Removed the duplicate lower-left artboard dimensions. Headings align dimensions to the right, move them into compact Rename/Delete menus when crowded, truncate long names and keep screen-space labels separate during extreme animated zoom.
- Cancelled canvas move/resize/draw previews and pending artboard renames when their originating project, page or canonical revision changes, preventing a late release or Enter key from editing a replacement document with retained IDs.
- Replaced Fiber v9's internally constructed deprecated Clock with a Three.Timer-backed compatibility port scoped to Fiber's own import, preserving Three class identities, demand/manual timing and balanced tab-visibility listeners. Explicitly disabled 2D shadows with PCFShadowMap instead of Fiber's removed PCFSoftShadowMap default; browser console checks capture all warnings/errors without suppressing messages.
- Replaced outlined guide numbers with upright, high-contrast measurement badges that remain a consistent screen size at different zoom levels.
- Corrected tooltip shortcut contrast in both themes, grouped theme and shape-category controls with shadcn ButtonGroup, shortened library search copy and respected reduced-motion preferences for interface transitions.
- Kept layer-drop insertion intent stable while rows animate, retargeted stationary-pointer drags after native tree scrolling, accepted valid drops into temporary layout gaps, and expanded collapsed group destinations during the preview without changing saved collapse preferences.
- Rejected stale layer drags after authoritative project/page changes, including deferred task execution, and avoided undo/history entries when a layer returns to the same insertion and parent.
- Guarded project-name drafts against a project switch before blur or deferred execution, and prevented late dashboard work from dismissing a replacement dialog.
- Serialized dashboard creation, imports, project opening and management mutations through one operation gate. Busy controls cannot start competing project operations, and unmounted gallery requests cannot close a replacement dashboard.
- Corrected card-name styling so plain names are distinct from explicit rename fields, matched rename/action heights and revealed neutral card controls on hover or keyboard focus. Thumbnail slides retain their outgoing lease until the transition settles.
- Made the spotlight SVG import produce validated editable vector layers in one atomic transaction, with stale-destination and bounded-file checks.
- Preserved stacking order when ungrouping layers and correct insertion positions when reordering an inverted layer list.
- Corrected render-target orientation through nested groups, masks, effects and exported images on both rendering backends.
- Corrected referenced mask coordinates, ancestor visibility/opacity handling and group confinement.
- Prevented color conversions, blend branches and GPU temporary values from producing incorrect output across backend fallbacks.
- Preserved SVG viewBox offsets, transforms, even-odd holes, `none` paints and inherited `currentColor`; rejected unsupported group-opacity structures instead of flattening them incorrectly.
- Made imported/brand artwork retain its original paints, while explicit fill changes enable recoloring and original colors can be restored.
- Removed the page-preview sentinel collision, corrected hit testing after paint-only updates and restored previews on pointer cancellation or lost capture.
- Prevented shortcuts from intercepting text fields, sliders, menus and other interactive controls.
- Protected the last valid GPU frame when a new allocation exceeds the cache budget; shared disposal waits for pending work and runs once.
- Prevented stale IndexedDB comparison caches, reserved identifier corruption, duplicate originals and partial import transactions.
- Reconciled restored documents by content fingerprint rather than timestamps alone; recovered journal writes with checkpoints after initialization or persistence failures.
- Made inactive renaming atomic with its journal entry, protected concurrent edits, and preserved exact accounting through legacy migrations, pruning and deletion.
- Cancelled abandoned StrictMode startup work before persistence, avoiding duplicate first-launch projects.

### Verification

- Deterministic rules reject tests under `src/`, missing mirrored tests, files over 600 lines, invalid core dependencies, native WebGPU engine code and production GPU readbacks.
- Coverage includes all executable sources with an 85% minimum for every metric and an independent core threshold. Oxlint type-aware checks, React Hooks checks and Oxfmt are part of the gate.
- Real browser tests compare GPU and fallback pixels, alpha, effects, masks, guides, live previews, exports, project management and video decoding.
- Native artboard checks verify decoded persisted previews, unchanged view/context count across activation, local drag/undo, ruler targeting and artboard CRUD with zero JavaScript pixel readbacks. Motion checks measure anchor preservation, monotonic trajectories, interruption and zero editor React commits during animation frames; color checks exercise vertical hue/alpha gestures on real GPU pixels and native-picker availability, with mocked lifecycle checks for the unavailable headless OS picker.
- Reproducible workloads cover 50 local image layers with 100 effects and a native IndexedDB journal containing 100,000 entries. Reports count actual readbacks, React commits, resource changes and database reads/writes.
- Real pinned segmentation weights have been checked on WebGPU and in a fresh WASM worker with external networking blocked after caching.
