# Changelog

All notable changes are recorded here in English. MusArt uses a synchronized [Semantic Versioning](https://semver.org/) release number across its workspaces.

## [Unreleased]

### Added

- **Local model manager:** worker download progress reports actual pinned-model bytes, percentage and initialization separately. Model data can be inspected, loaded, canceled and removed independently of projects; deletion preserves other model resources and the shared runtime cache. Development prebundles the lazy ML dependency to prevent optimizer rediscovery from reloading the editor.
- **Scoped attachment thumbnails:** image, effect-stage and mask-coverage cards request their real artboard and GPU dependency graph, including inactive compositions. Mask previews preserve actual alpha/luminance/inversion semantics; disabled-source changes invalidate cached coverage. Shared row admission prevents visible thumbnails from flooding the bounded preview queue, while cancellation and URL cleanup reject stale page results.

- **Actual smart snapping:** move and resize gestures attract to visible layers/groups, artboard edges/centers and manual guides using a zoom-independent screen tolerance. An indexed resolver excludes the moving subtree and mask sources, preserves nested transforms and aspect constraints, and displays alignment/gap cues only while a real snap is engaged. Alt temporarily bypasses attraction; completed gestures remain one undoable edit. Inclusive attraction boundaries tolerate only float32 CSS-transform round-off, preserving the six-pixel limit at fractional internal zoom values.

- **Searchable snapping preferences:** command search can enable or disable snapping and open Editor settings directly. Attraction distance is stored as a small versioned user preference in screen pixels, independent of project history.
- **Compact snapping preview:** the real pointer/keyboard snapping sandbox opens in a Radix popover, keeping the preferences panel's layout fixed and releasing its gesture, observer and subscription when dismissed.
- **Preferences sidebar:** General, Appearance, Shortcuts and Editor categories share one accessible settings window with compact colored navigation tiles. The inline shortcut editor reuses the actual recording/reset controls, while editor snapping and its screen-pixel attraction distance use the same persisted preferences as canvas gestures. A disposable pointer/keyboard playground exercises the same snapping resolver without editing the open project.
- **Individual guide colors:** every guide has the shared compact color picker, live imperative preview, cancellation and one undoable color commit. Colors persist in portable documents and history; newly added panel, preset and ruler guides reuse the last chosen user color, with pink as the default.
- **Persistent pixel selection:** the magic wand shows retained marching ants, adjusts tolerance by dragging, supports New/Add/Subtract/Intersect and contiguous color matching, and accepts selections without editing the image. Shift adds, Alt subtracts, cancellation restores the previous region, and explicit Create/Replace mask publishes one undoable grayscale luminance mask. A bounded worker reuses the original pixels, rejects stale targets and oversized sources, and sends simplified display outlines while retaining exact mask coverage.
- **Project layer tree:** every artboard has an independent collapsible root in one virtual list. Activating or adding an artboard preserves the viewport, inactive rows activate their real page, and page-scoped preview requests keep their thumbnails truthful.
- **Property label resets:** double-click a numeric scrub label to restore the property's default, including typography, effect settings, opacity, image scale and replay options. Reset cancels an active draft, resolves mixed selections atomically and creates one undo entry only when document values change. A short neutral pulse respects reduced motion and releases its timer on unmount.
- **Guide format presets:** a compact branded social/video picker previews real catalogue aspect ratios and dimensions, then appends editable centered framing guides in one transaction. Existing guides, target sizes and layout metadata are preserved; orientation groups use concise labels and ruler switches retain genuine shadcn sizing.
- **Visible project templates:** the dashboard exposes the editable AFTERHOURS techno poster alongside canonical social, print and screen canvas formats with original brand icons. Selecting a template creates an independent, validated and saved project; the poster preview is exported from its real GPU composition.
- **Magic Search:** a keyboard-accessible Ctrl/Cmd+K spotlight with categorized tools, imports, project and viewport actions, effects, pages, cross-page layers and a shortcut reference. Search normalizes accents, reports available/disabled actions and routes operations through the existing engine and services.
- **Scroll surfaces:** reusable boundary shadows update imperatively across the dock, inspector, layer tree, palettes, effect popovers and command lists. Thin scrollbars share one theme; short viewports retain normal vertical scrolling and 33-pixel dock controls. The customization catalog virtualizes its visible command rows, while native dock dragging previews spring transitions and persists only a valid completed reorder.
- **Customizable dock:** a compact **…** spotlight trigger and persistent pinned shortcuts drawn from the shared action/effect registry. Drag reordering has a local visual preview; the customization popover provides searchable pinning, unpinning and keyboard-accessible move buttons. Stored command IDs are allowlisted, deduplicated and bounded independently of document history.
- **Font library:** a searchable, categorized and virtualized Google Fonts picker, selected-text hover/keyboard previews, cancellable drafts and single-edit application. TTF/OTF imports and selected downloads persist across projects in a browser-wide IndexedDB library. Supported browsers discover local font metadata on picker opening through native permission controls; originals are read only when chosen. Projects retain family references rather than embedding font binaries.
- **Techno poster template:** a real, lazily loaded **AFTERHOURS — Techno** artboard action in Magic Search and dock customization, with editable typography, gradients, groups, wireframes and GPU effects. Adding it is undoable and a project switch cancels a stale template request.
- **Analytical GPU text:** a strict TypeScript and TSL port of the ts-slug curve/band approach, instanced glyphs, local outline fonts, HarfBuzz shaping, kerning, ligatures, variable weights and native-scale export. Text fills support linear/radial RGBA gradients with two to eight stops and hard transitions, while keeping masks, effects and blend modes in the existing GPU graph.
- **Text quality controls:** zoom/device-density preview resolution with bounded retained-target allocation, explicit font provenance and tests that detect Canvas2D text raster calls as well as GPU readbacks.
- **Creative editor:** a central multi-artboard canvas, floating left dock, compact project menu and name pill, export beside Design/Animate, and a pinned inspector split from the layers panel with resizable dividers.
- **Shared artboards:** project pages appear together in a deterministic workspace, with screen-sized headings, direct activation, rename/delete menus and destination-aware image drops. One retained editing scene serves the active artboard; inactive artboards lease real persisted GPU thumbnails only while visible. Switching artboards preserves the world view and page-local tool/guide coordinates.
- **Canvas quick add:** a contextual plus in the active artboard heading reveals on artwork/header hover or keyboard focus and adds an artboard through the shared command registry. Double-clicking empty workspace opens a compact categorized, searchable Radix popover backed by Magic Search's addable commands. Text and primitives become centered editable layers in the active artboard; imports keep native file-picker activation and shapes open the existing shapes/icons/brands library. Artboard content is excluded from the double-click gesture, and stale or playback sessions cancel safely. Both add/options controls include translated Radix tooltips.
- **Shared GPU previews:** bounded, deduplicated layer/effect and export previews borrow the existing thumbnail renderer, reject stale/aborted results and retain at most 64 blobs within 8 MiB. Explicit export previews take priority after pointer release without waiting for the background quiet timer.
- **Compact color picker:** a saturation/value pad with genuine vertical hue and alpha sliders, direct hexadecimal editing and a native screen-color picker where supported. Sampling preserves the chosen alpha, cancels abandoned requests and rejects stale results; previews remain imperative, with one committed undo entry per completed gesture and restoration on cancellation.
- **Themes and accessibility:** English and French interface resources, light/dark/system themes, saturated blue primary controls, shadcn/Radix Select, Tabs, menus, dialogs and Kbd hints, and tooltips without decorative arrows.
- **ResumI controls:** reusable scrub-label numeric inputs with direct typing, units, snapping, keyboard editing, cancellation and one committed edit per gesture.
- **Document engine:** validated portable projects, multiple pages, nested layers and groups, selection, atomic command transactions, undo/redo, alignment, distribution and world/local geometry utilities. Commands are dispatched through a typed registry to domain-specific handlers.
- **Layer attachments:** a virtualized tree presents ordered effect children and linked mask references beneath their owner, with real parameter popovers, per-effect blend/opacity, palette presets, visibility, removal and effect-stack drag reordering. Visible rows request abortable final GPU thumbnails and explicitly revoke their blob URLs.
- **Layer editing:** rename, duplicate, reorder, group, ungroup, visibility, locking, opacity, transforms, image aspect locking, text content and typography, fills, strokes and layer-specific effects. Dragging projects the layer tree live with reduced-motion-aware spring transitions; nested-group and Alt-mask targets are validated without changing the document until drop, and cancellation restores the original order.
- **Shapes and artwork:** a unified last-used shape tool with long-press, right-click and keyboard access to searchable, virtualized shape/icon/brand catalogs copied from ResumI. Original multicolor paints and attribution are retained; supported SVG artwork can be imported as editable vector data.
- **Guides and layout:** editable page/layer guides, draggable rulers, margins, padding, snapping, alignment and distance arrows, including nested group transforms. Social and print presets include appropriate dimensions, editable safe areas and real platform marks.
- **GPU composition:** Three.js WebGPURenderer, React Three Fiber and TSL, with the same node graphs on the WebGL fallback. Retained render targets, ping-pong effects, normal-layer batching, isolated groups, bounded resource caches and demand rendering keep intermediate pixels on the GPU.
- **Blending:** 26 layer/group blend modes, including darker/lighter color, darkening, lightening, contrast, difference and hue/saturation/color/luminosity families, with alpha-aware compositing.
- **Effects and corrections:** modular GPU effects and adjustments: dither, ASCII, procedural gradients, brightness, contrast, grayscale, blur, exposure, saturation, hue, vibrance, temperature, tint, gamma, invert, sepia, threshold, posterize, grain, halftone and vignette.
- **Color workspaces:** sRGB, Display-P3 working-space conversion to the current sRGB output, and a generic CMYK soft proof. Raster exports remain RGB; the proof does not claim ICC press-profile support.
- **Masks and selections:** non-destructive asset and layer/group masks, alpha/luminance coverage, inversion, enable/disable controls, mask drag/drop affordances, dependency-cycle validation, a connected-color magic wand and local SlimSAM object segmentation.
- **Import and export:** bounded bulk image imports, drag/drop and clipboard handling, portable `.musart` documents with originals, PNG/WebP/JPEG through native browser encoders, multi-page ZIP exports, and reusable GPU render sessions.
- **Local projects:** IndexedDB manifests and original assets stored separately, transactional writes, coalesced autosave and restoration of the last project.
- **Project library:** paginated cards, creation, opening, inactive-project renaming, duplication and deletion. Thumbnail-first cards keep page names and project management actions in readable overlays; a hover-only carousel slides horizontally every 1,400 ms, pausing for keyboard focus, hidden/offscreen cards and reduced-motion preferences. Manual swipe, arrow and dot navigation is not exposed.
- **Shared dashboard:** the MusArt logo opens Projects and Templates with a neutral animated tab indicator, a portable-project import action and a clear custom-canvas creation flow. The same interface welcomes first-time users without persisting a placeholder project. The settings gear opens preferences and the customizable shortcut editor; preferences also remain accessible through Magic Search.
- **Thumbnail pipeline:** native WebP encoding, revision checks, lazy blob URL leases, a bounded retained GPU session and idle scheduling that pauses during interaction. Deleted projects and stale page revisions cannot be republished by delayed jobs.
- **Storage insights:** per-project logical payload breakdowns, cached incremental counters for originals, thumbnails and history, and a separately labelled browser origin storage estimate. Projects expose a confirmed clear-history action.
- **Durable creative history:** an automatically recorded journal separate from the project manifest. It stores completed transactions as compact deltas and action summaries, with sparse checkpoints, original-asset pooling, bounded pagination and adjustable retention from 10 to 100,000 entries; the default is 10,000.
- **Timelapses:** deterministic replay and scrubbing in Animate, a separate JSON history export, and MP4/WebM encoding through Mediabunny from a retained GPU canvas with explicit timestamps and encoder backpressure.
- **Headless tools:** document creation, atomic command application, still rendering and editor screenshots, plus an opt-in automation API for document, history and thumbnail operations.
- **Branding:** the supplied transparent MusArt logo, favicon, Apple Touch icon and installation icons, preserving the original artwork and resolutions.
- **Open-source preparation:** MIT project license, English README and contribution documentation, preserved third-party licenses, local asset provenance, and official Meta/Cerebral Valley hackathon references.
- **Version management:** synchronized workspace versions, a deterministic version checker and a release script that moves reviewed `Unreleased` notes into dated releases.

### Changed

- Magic-wand settings expose tolerance and bilingual help, with advanced connected-color matching inside that help. Labelled, translated tooltip actions distinguish keeping a selected area from erasing it. Ctrl/Cmd+D clears pixel selection; Delete/Backspace apply an editable inverse mask in one undoable transaction, preserving existing clips and original image bytes. Attachment deletion retains priority. The retained selection outline now sits in viewport coordinates with a single screen-pixel stroke and stable dash animation across zoom and nested transforms.
- Appearance values use the same segmented surface as workspace tabs with genuine single-choice radio semantics; the snapping-distance scrub handle stays compact while retaining its translated accessible name.
- Effect opacity scrub labels consistently use the Sun icon, including dither. Layer visibility, attachment and footer actions have larger square hit areas with equal padding on every side, clearer spacing and separately labelled creation/selection groups.
- Artboard activation retains stable real preview backdrops beneath the shared editing canvas. Switching or adding pages no longer replaces available artwork with a preparation panel or restarts the initial reveal; exact certified frames can be reused from the existing bounded GPU cache, with readiness acknowledged only after their matching draw.
- Guide preset categories reuse the same segmented Radix tabs as Projects/Templates. The picker and cards retain fixed heights across filters, with smaller original brand marks, distinct decorative gradients, true format proportions and safe areas taken from the catalog; append geometry is unchanged.
- Project manifest and thumbnail persistence now share a lazily owned worker with bounded fragmented input, atomic compare-and-swap writes and small acknowledgments. Background thumbnail header/blob reads use that worker too. The worker-unavailable path retains the same real transaction; a lost write acknowledgment reports an uncertain result that requires reopening rather than silently replaying an old save.
- Shared-workstation verification runs one heavy command at a time with bounded workers, low priority and enforced CPU/memory limits. The performance protocol records those limits and keeps capped timing cohorts distinct from earlier uncapped measurements.
- Closed canvas quick-add popovers now skip catalog construction and search normalization during document publications; opening retains the shared actions, query filtering and stale-session cancellation.
- Engine publications expose weak identity certificates for validated immutable projects and pages. Capture-only replay transitions preserve exact completed commits without preparing deltas inside engine listeners.

- Dark editor surfaces now use neutral gray tokens and opaque floating panels to prevent bright artwork tinting their backgrounds. Design/Animation remain genuine shadcn tabs; alignment controls have distinct horizontal/vertical groups, and narrow Inspector fields show icons while retaining their accessible names.
- Magic Search uses a short Motion entrance and blur reveal for only the bounded mounted result rows. Reduced-motion preferences bypass the animation, and animation frames do not publish editor React state. Animate uses compact history/video cards and a shared scrolling surface that keeps export controls reachable in short sidebars.
- Project saves reuse the engine's private certificate for validated, deeply immutable publications, avoiding a second complete snapshot clone/freeze and validation. External objects, including deeply frozen ones, still receive detached snapshots and full validation; queued saves retain their original captured values while the engine advances.
- Exact certified page/original-collection identities share one pending or completed thumbnail digest across saving and preview scheduling. - Canvas geometry subscriptions compare typed fields and exit on the first changed value instead of serializing the complete layer tree after every commit. Equal guide and inset values retain the view snapshot, while geometry, page metadata and selection remain reactive.
- Closed spotlights update dock availability from cached static command metadata without preparing document rows or normalized search terms. Document indexing is lazy on opening, with weak snapshot ownership and reuse across unchanged metadata. App and layer controls share one read-only selection analysis for immutable page/selection pairs; mutable inputs are rechecked.

- Layer thumbnails track their actual selected render graph instead of the global edit revision. Unrelated edits and metadata changes retain existing previews, while descendant paint, ancestor processing, masks, working color space and referenced originals invalidate the affected results. Weak asset aliases recognize equivalent original-object clones without retaining image bytes in signature tables.
- Layer scrolling updates the React window in bounded row batches while tracking native scroll offsets immediately; scrolling within the existing window performs no React state update.

- Commit observers can request frozen command types without cloning full patch payloads. Replay observers can capture exact immutable transitions immediately and defer delta construction to an ordered platform scheduler; portable session recording retains its synchronous detailed behavior.
- Revisited spotlight command states reuse a bounded eight-state cache of prepared rows and normalized search terms. Document-label, language and shortcut changes invalidate the corresponding cached data without retaining older document revisions.

- Alignment chooses the common group, selection bounds or artboard automatically. Numeric fields display at most two decimals while preserving untouched document precision; Design/Animate tabs and layer rows use neutral active states.

- Bulk per-layer patches use one indexed command and one undo entry, including distinct transforms across 10,000 selected elements. Selection validation and immutable geometry lookup use reusable indexes instead of repeated document scans.
