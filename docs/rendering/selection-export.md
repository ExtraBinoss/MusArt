# Selection export

The export popover captures a canonical document snapshot. With a selected layer or group it exports cropped content by default; the whole-artboard switch restores the original canvas dimensions and background. Multi-artboard output remains an explicit ZIP option. Scale changes affect delivered resolution rather than the size of the preview viewport.

`selectionComposition` is a pure core operation. It keeps selected subtrees and their ancestor processing, computes pixel bounds with a small floating-point edge tolerance, and translates root transforms into that crop. Referenced mask subgraphs are copied under deterministic private IDs, including their required ancestor transforms and chained masks. Separate copies prevent a partially selected mask group from losing content needed by another selected layer. Effect and guide IDs are remapped as well; original assets are referenced without copying their bytes. Callers reserve project, page and asset identities. The derived graph is render-only and does not modify the project or its undo history.

Preview requests share the retained thumbnail renderer and bounded queue. The export popover requests foreground priority after input release; background layer thumbnails remain deferred during active gestures. Originals and the complete enabled effect/mask stack use the same document-resolution reference as the canvas, then GPU mipmaps reduce the processed output. Cached encoded blobs are reused, while consumer signals, canonical frame and requested-size checks, and owned blob URLs reject stale results and release abandoned resources.

The preview fits the selected scope's dimensions inside the measured viewport, including its padding and reserved scrollbars. A resize observer and browser resize events select the displayed physical resolution from the viewport and device pixel ratio before requesting the blob. Enlarging requests up to twice that fitted size and enables scrolling; both the encoded edge and the displayed physical edge are capped at 768 pixels, so the limit can reduce the enlargement below 2×. Changing preview size requests an appropriately sized render without remounting the frame or reading GPU pixels into JavaScript. The output export scale remains independent of the preview viewport.

Mirrored tests cover crop values, rotated parents, shared and chained mask dependencies, private ID collisions, dual paint/mask roles, 10,000-element batches, stale frames, cancellation and URL cleanup. `test/browser/export-selection.spec.ts` decodes real delivered files, checks selected alpha and full-artboard pixels, exercises preview scrolling, and instruments the production read APIs separately from image inspection.
