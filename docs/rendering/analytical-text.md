# Analytical text in Three/TSL

MusArt's text layers use an analytical curve renderer rather than Canvas2D glyph bitmaps, SDFs or tessellated outlines. The reference is the project owner's [ts-slug](https://github.com/ExtraBinoss/ts-slug), inspected at revision `a8a47a8bb0a35cde92bafaf52934a3c0a21e9674` on October 27, 2026. The local checkout in `third_party/clone/ts-slug` is ignored by Git and is never imported at runtime. MusArt's implementation lives in `packages/render/src/surface/text/`.

The reference credits Eric Lengyel's Slug algorithm and the JSlug/Sluggish ports. MusArt rewrites curve generation, instanced geometry and ray coverage as strict TypeScript and Three.js TSL. Its materials do not inject GLSL, WGSL, ShaderMaterial or native WebGPU pipelines. The source repository currently lists license documentation as a TODO; this reference is recorded explicitly rather than being described as an MIT dependency.

The dynamic-dilation and weighted-coverage port additionally follows Eric Lengyel's [official Slug shaders](https://github.com/EricLengyel/Slug/tree/be3c13eb7d63f9e8aa5c583e42d92c374cb91d98) at `be3c13eb7d63f9e8aa5c583e42d92c374cb91d98` and Konstantin Paulus's [WebGPU translation](https://github.com/diffusionstudio/slug-webgpu/tree/12d8bdf333263c1340a7ca5de0c36f7f90721be0) at `12d8bdf333263c1340a7ca5de0c36f7f90721be0`. Their MIT notices are preserved in [Slug](../legal/slug-eric-lengyel-MIT.txt) and [slug-webgpu](../legal/slug-webgpu-MIT.txt). Both reference clones remain ignored; their native pipelines and shader strings are never imported. The WGSL snapshots are preserved verbatim in the tracked reference directory; [the function mapping](slug-port.md) lists every ABI and numerical adaptation explicitly.

## Preparation and ownership

- Twenty local TrueType families ship with OFL notices and a [pinned source/checksum manifest](../../apps/web/public/fonts/manifest.json), spanning sans, serif, mono, display and handwriting styles. The font loader retains five recent idle faces; active preparation leases protect native font objects from eviction. Legacy Arial, Georgia and monospace family values resolve to Arimo, Tinos and Roboto Mono; unknown system-family values resolve to Inter consistently across devices.
- OpenType.js parses outlines and variable glyph coordinates. HarfBuzz shapes font metadata, including kerning, ligatures, glyph offsets and variation advances. HarfBuzz buffers, fonts, faces and blobs are destroyed explicitly. These CPU operations prepare reusable font data and never read rendered pixels.
- The layout engine wraps tokens and clips the visible text frame. Preparation normalizes decomposed text to NFC without editing the portable document. This is a horizontal editor layout; mixed-script bidirectional paragraph layout and color emoji are not yet supported. The user-wide [font library](../guides/fonts.md) supplies imported, Google and browser-discovered local outlines through the same resolver used for preview and export.
- Quadratic outlines stay exact. Cubic outlines are recursively converted to quadratics with a 0.125-font-unit sampling tolerance and a bounded subdivision depth. Both horizontal and vertical band lists index the curves. Atlases hold curve coordinates and indices, not glyph pixels.
- Glyphs are instanced quads with exact outline bounds. TSL expands their vertices from the active MVP and physical target viewport, then conservatively covers the inverse-Jacobian half-pixel footprint used by analytical derivatives. This also handles independently rounded target axes, rotations and affine shear. Coverage and gradients interpolate the same dilated layer-space point, while the surface camera still clips to the authored text frame. Cached geometry excludes paint, opacity, position and export scale. The GPU cache accounts for the atlas and instance buffers; eviction disposes their textures, geometry and materials. Hidden ancestor branches are skipped and failed or cancelled preparation cannot republish resources after disposal.

## GPU coverage and paint

Each fragment solves quadratic intersections in its horizontal and vertical bands. Slug edge weights combine their consistently signed coverage estimates, with the minimum absolute coverage as the interior fallback. The implementation does not apply an optical weight boost or change the nonzero fill rule. Derivatives provide the actual pixel footprint. Coefficients are formed before fragment translation to avoid float32 cancellation on straight contours, and quadratic roots use the stable q formulation with the reference1/65536 linear threshold in font-design-unit coordinates. Shared TSL expressions are assigned before conditional root branches; lazy expressions first evaluated inside one branch must not be reused as though assigned in another. Linear roots use guarded denominators. Root eligibility uses portable TSL sign-bit operations, including signed-zero endpoints. Band references are sorted by descending ray-axis maxima and overlap by 1/1024 em; parallel lines remain excluded, and traversal exits once the remaining curves cannot reach the current pixel. Curve coordinates and integer-exact references retain the bounded Float32 atlas rather than blindly narrowing our font-unit/global-index representation to 16 bits. The reference port's artificial diagonal bow is not used.

Instanced glyphs use premultiplied maximum blending to union overlapping coverage. Negative tracking therefore does not compound a semitransparent fill. All glyph instances sample the same layer-space paint at a given position. Solid RGBA, linear and elliptical radial gradients support two to eight ordered stops, alpha and duplicate-offset hard stops. Linear angles use pixel-space direction with 0° left to right. Paint parameters remain stable uniforms during scrubbing.

The resulting GPU texture enters the existing isolated layer/group pipeline. All layer blend modes, masks, effects and working-space conversion apply normally. There are no production glyph raster calls or GPU pixel reads into JavaScript.

## Preview and export density

The editor follows zoom and actual browser device density independently, including a display/DPR change without another canvas zoom. A single 140 ms quiet update adjusts the R3F drawing buffer and composition scale together. Above 1×, stable quarter-density steps avoid wasting an otherwise useful intermediate quality tier; below 1×, the requested physical footprint remains explicit. Original textures and glyph outlines stay reusable. The estimate counts actual primitive batches, clipped group targets, text/vector targets, shared effect scratch and fixed 1× effect/mask references separately. It keeps the 192 MiB target estimate, 64-megapixel/API edge bounds and acquired device texture limit. Original image/video source reservations participate in a separate total estimate; the renderer's unchanged 384 MiB hard cache remains the real admission guard for retained and in-flight resources. Incompressible originals are not reduced to a one-pixel preview without benefit. Large compositions can still be below screen density at extreme zoom; exports retain their explicit scale. See [live preview density](../performance/preview-density.md) for native evidence and limitations.

Native PNG/WebP/JPEG and video exports consume the same GPU graph. Low-scale output receives target-pixel dilation automatically, without rebuilding cached instance buffers or stretching paint coordinates. Neither export nor preview uses a Canvas2D text layer.

## Verification

Mirrored tests cover outline conversion, bands, local font loading, shaping, wrapping, live paint uniforms, resource cleanup, visibility and failure paths. `test/browser/text-rendering.spec.ts` independently checks real WebGPU and WebGL fallback pixels: counters, alpha, color, gradients, tracking, weight, kerning, accents, masks, effects, blending and sharp high-density preview/export. `test/browser/text-outlines.spec.ts` also compares diagonal and straight glyph interiors against the original font paths rendered by an independent browser reference. `test/browser/text-dilation.spec.ts` additionally compares thin glyphs at low/normal density and integer/half-pixel phases against original font paths, including an anisotropic clipped frame. These suites instrument actual read APIs before boot and inspect delivered images in a separate page.

Primary references: [Three TSL API](https://threejs.org/docs/pages/TSL.html), [InstancedBufferAttribute](https://threejs.org/docs/pages/InstancedBufferAttribute.html), [OpenType.js](https://github.com/opentypejs/opentype.js), [HarfBuzz.js](https://github.com/harfbuzz/harfbuzzjs). Versions are pinned in the workspace manifests and lockfile.
