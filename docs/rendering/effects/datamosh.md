# Datamosh · Block Smear

This is a deterministic spatial approximation of datamosh aesthetics for a photograph or rendered layer. It does not decode damaged video, remove I-frames, estimate optical flow or retain previous frames. Its UI says Block Smear and Spatial Smear deliberately. Explicit pattern time can select another seeded block field; it cannot create real motion history.

The primary visual reference is Takeshi Murata's [Untitled (Pink Dot), distributed by Electronic Arts Intermix](https://www.eai.org/titles/untitled-pink-dot), including its [published still](https://www.eai.org/user_files/images/title/murata_pinkdot_xl.jpg). Inspection shows fractured photographic fragments, coherent colored smears and retained source detail; no footage or artwork is used as an app asset. Rosa Menkman's [Vernacular of File Formats](https://beyondresolution.info/0001) provides the primary distinction between compression structures and generic image distortion. The original work is temporal; this effect borrows its visual vocabulary while documenting the spatial approximation.

An authored-pixel macroblock grid selects affected blocks with the existing cross-backend integer hash and document seed. Local and row-correlated fields determine displacement angle and magnitude. Four fixed source samples create a spatial trail, two additional source samples offset red/blue channels, and bounded quantization controls color fragmentation. All source reads use the common orientation-aware sampler, and the original per-pixel alpha is returned unchanged. Density zero and amount zero select the exact original. At 256 color levels, sampled RGB remains continuous until the common premultiplied output, avoiding an extra quantization of interpolated source colors. With displacement and chroma shift zero, this maximum-precision mode is exactly neutral even at full smear, because a trail without displacement samples the same image position.

The pattern phase is `floor(time × rate) mod 4096`; it repeats after 4096 field states. This keeps integer coordinate offsets exactly representable in the supported float range. Rate zero freezes the field regardless of explicit time. Source preparation, effect reference density and final GPU mip filtering follow the common WYSIWYG contract; zoom cannot alter macroblock registration or reseed the field. There are no extra textures, history buffers, timers or GPU readbacks. Shared coordinates, hashes and sample values are materialized in the outer TSL function before any conditional selection.

Native acceptance requires both backends on a real photograph with fractional alpha, exact neutral controls, visible block fragmentation without destroying all photographic detail, deterministic same-seed/time output, distinct seed/phase, frozen rate, independent coherence/direction/smear/chroma/quantization behavior, source-alpha preservation and exact matched-density editor/export. Known color ramps verify displacement direction and blocked boundaries. Reports and inspection PNGs belong under ignored `artifacts/datamosh/`.

## Native evidence

On October 28, 2026, both native cases passed on Chromium 156, Linux, Intel Xe-LPG WebGPU, viewport 1600×1000, DPR 1. The real 1280×960 photograph was prepared natively with graded alpha. The default corrupted 18,430 of its 36,864 authored image pixels while retaining 11,863 distinct opaque colors and all 98 source-alpha levels exactly. Changing seed, phase, block size, coherence, smear and color bleed independently changed the intended field or color channels. Color bleed left green and alpha byte-identical. Equivalent explicit phases (time 0.5/rate 2 and time 0.25/rate 4) were exact, as was the frozen-rate case.

Every editor-canvas RGBA byte matched the same-density export at 50%, 100% and 200%, and every 1× reference pixel matched its 2×2 export block. Zero density and maximum-precision zero displacement/color bleed were exact source identities, including full smear and fractional alpha. The two-level red/green ramp produced exactly four opaque colors. An independent integer-hash oracle predicted the row-wise offsets for 36,864 pixels in each 0°/90° ramp check, with a maximum one-byte error and mean errors 0.01785/0.02821. All production readback probes recorded zero and both error logs were empty.

The initial native test exposed a genuine neutral-endpoint error: quantizing interpolated straight RGB before premultiplication changed 2,938 channels, up to one level on opaque pixels and five on fractional alpha. Those images remain in `artifacts/datamosh-before-neutral-fix/`. Maximum precision now preserves the continuous sample and its exact identity, rather than weakening the zero-error gate.

Visual inspection of both processed PNGs confirmed coherent horizontal streaks, broken photographic blocks, chromatic fringes and retained waterfall detail. The independent ramp images confirmed directional displacement rather than painted noise. The result matches the referenced spatial vocabulary while making no claim to reproduce video decoding or motion history. These are correctness witnesses, not frame-rate measurements.
