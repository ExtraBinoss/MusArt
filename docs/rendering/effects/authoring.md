# Shared procedural effect authoring

Each effect owns pure metadata in `packages/core/src/effects/<id>/definition.ts`, its Three.js TSL graph in `packages/render/src/effects/<id>/`, and English/French resources under the web effect library. The registries contain definitions/builders only. Imported settings reject unknown names, wrong types and out-of-range values. Scoped values are resolved once per uniform update, with stable uniform identities; choice values use their declared option index and colors use encoded working RGB.

Definitions also declare whether raw treatment coverage is preserved or may be reduced. Preserving builders retain the source-alpha graph directly; ink opacity and transparent cuts declare reduction and have native default/partial-cutout witnesses. Optional Porter-Duff compositing remains a separate operation.

All spatial fields use authored layer dimensions. The complete stack, masks and isolated descendants use the common authored 1× reference and premultiplied GPU mip transport. A shader must not branch on editor zoom or change its seed with raster density. New seeded builders use the exact unsigned-integer seed uniform and keep seed offsets/frame additions integer through hashing; the legacy float port preserves older treatments. Periodic phases are reduced before multiplication by 2π or combination with spatial coordinates, avoiding Float32 loss at large valid times. Test-only PNG decoding is isolated from production readback accounting.

An optional radial gizmo describes normalized center keys, an outer radius, an optional protected radius, radius units and optional ellipse aspect/rotation keys. The canvas derives its geometry from that metadata, including nested owner transforms, without an effect-type switch. Handles publish imperative layer previews; a completed drag commits one validated command. Escape, pointer cancellation and stale document/selection guards restore the original. Arrow keys move handles by one document pixel; Shift uses ten. Fixed-size pointer handles resolve overlaps by screen-space proximity, including nested transforms; the center takes exact ties and every handle remains keyboard accessible.

Effects with a top-level `time` parameter receive explicit live playback controls. Playback publishes at most thirty phase previews per second through the existing imperative preview adapter. It creates no per-frame App, Inspector or canvas React state. Pause commits the most recently requested phase once; Escape cancels. Outside input, hiding the tab and window blur stop playback. Unmount releases listeners and the pending RAF and cancels an unfinished preview. Export opening and native image/project export freeze active phases for that engine before capturing the canonical project. Other editor instances are isolated.

The live control does not invent simulation history. A shader with explicit phase can be deterministic and animated; a static photographic approximation such as compression-style Datamosh is documented as such. GPU output, resource bounds, actual decoded exports and real input gestures must be verified separately from graph topology tests.
