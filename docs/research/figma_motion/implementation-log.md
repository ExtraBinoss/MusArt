## Frozen temporal contracts used by the first code

| Contract                   | Implementation rule                                                                                                                                                                                                                                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Exact time                 | Safe integer `{ value, rate }`, positive rate; signed values are allowed for offsets. Frame rates are rational `{ numerator, denominator }`. Imported equivalent fractions compare equally.                                                                    |
| Key coordinates            | Keys use composition-relative time. Track placement shifts its keys and group descendants; trimming changes presence and retains off-range keys.                                                                                                               |
| Whole-duration presence    | `end: null` follows composition duration. Explicit trimmed ends remain fixed. Longer placement may extend duration without shortening other tracks.                                                                                                            |
| Static                     | Authored base values render/edit; dormant timing and keys remain untouched.                                                                                                                                                                                    |
| Easing                     | A destination key owns incoming easing. HOLD changes at the destination boundary; discrete properties never interpolate invalid intermediate values.                                                                                                           |
| Output intervals           | Offline evaluation is half-open. A typed terminal-preview option shows exact end-pose values with left-limit temporal presence; it never adds an extra exported frame.                                                                                         |
| Frame ownership            | Evaluation reports are immutable and belong to one frozen compilation; stale reports cannot be applied to another compilation of the same artboard.                                                                                                            |
| Hierarchy safety           | Grouping/reparenting/ungrouping affected animation currently rejects until correct timed transform baking exists. Layer order changes in the same coordinate system remain available. This is a visible temporary restriction, not completed hierarchy parity. |
| Default effect composition | Missing `composite` means replacement, not source-over. The animation registry exposes `default`; applying it removes the optional field.                                                                                                                      |

## First core-only profiling

Measured on Node 24.19.0, Linux 7.2.8, Intel Core Ultra 5 125H, at low process priority on the shared workstation. Each cohort has 200 warmup evaluations and 1,000 measured random-order samples. The fixture animates four properties with eight keys per layer; each layer has Gradient and CRT effects. **No shader, decoder, native input, React or browser presentation work is included.**

| Fixture                                                           | Evaluation p50 / p95 / p99 / max (ms) | Materialization p50 / p95 / p99 / max (ms) | Cold compile (ms) |
| ----------------------------------------------------------------- | ------------------------------------- | ------------------------------------------ | ----------------- |
| 50 layers, 100 effects, 200 animated properties, 1,600 keys       | 0.217 / 0.862 / 2.206 / 6.525         | 0.790 / 3.254 / 8.449 / 42.184             | 89.089            |
| 500 layers, 1,000 effects, 2,000 animated properties, 16,000 keys | 4.575 / 12.305 / 16.263 / 27.547      | 5.300 / 20.108 / 26.142 / 33.619           | 391.736           |

These results do not pass the full requested performance envelope. In particular, large-compilation startup, the 500-layer materialization path and recorded maxima still need work. A batch applier reduced the 50-layer materialization p95 from 4.882 to 3.254 ms in these runs; the 500-layer p95 remained approximately 20 ms. Shared scheduling and GC affect these short runs, so this is diagnostic evidence, not a portable speedup claim.

Frozen bundles, fixture script, previous/updated distributions and raw reports are retained under ignored `artifacts/motion/`. The historical photographic 50-image GPU workload is a different benchmark; its results are not replaced by these core-only numbers. Integrated browser, media, React and GPU budgets remain T16 work.
